# منصة تسجيل طلاب الصف الثاني عشر — تقنية المعلومات
### أ. فيصل العريبي — مدرسة جابر بن حيان للتعليم الأساسي

منصة يسجّل فيها الطلاب بياناتهم (الاسم، رقم الهاتف، الشعبة، كلمة مرور)، وتُحفظ البيانات فعليًا في **ملف JSON حقيقي** داخل مستودع GitHub خاص بك، عبر دالتين صغيرتين تعملان على Vercel. لا يوجد أي اشتراك مدفوع أو قاعدة بيانات خارجية.

## الفكرة باختصار

- المتصفح **لا يتحدث مع GitHub مباشرة أبدًا** (لتفادي وضع أي رمز دخول سرّي داخل كود الصفحة الذي يراه كل الطلاب).
- بدلًا من ذلك، الصفحة تتحدث مع دالتين خفيفتين على Vercel: `/api/register` و `/api/students`.
- هاتان الدالتان فقط — من جهة الخادم، بعيدًا عن أعين الطلاب — تستخدمان رمز دخول GitHub لقراءة وتحديث ملف `students.json` في مستودع **خاص (Private)**.

```
الطالب  →  index.html  →  /api/register (Vercel)  →  يحدّث students.json في مستودع GitHub الخاص
المعلم  →  admin.html   →  /api/students (Vercel)  →  يقرأ students.json من نفس المستودع
```

لهذا ستحتاج **مستودعين على GitHub**:
1. **مستودع الموقع** (عام أو خاص، لا فرق): يحوي ملفات هذا المشروع، ويُربط بـ Vercel لعرض الموقع.
2. **مستودع البيانات** (يُفضّل أن يكون Private): لا يحوي شيئًا سوى ملف `students.json`، ولا يصل إليه أحد سوى الدالتين عبر الرمز السرّي.

## محتويات المشروع

| الملف/المجلد | الوظيفة |
|---|---|
| `index.html`, `app.js` | صفحة تسجيل الطلاب |
| `admin.html`, `admin.js` | لوحة المعلم |
| `style.css` | التصميم المشترك |
| `api/register.js` | دالة Vercel لاستقبال تسجيل طالب جديد |
| `api/students.js` | دالة Vercel لجلب السجل (بعد التحقق من كلمة مرور المعلم) |
| `lib/github.js` | أدوات القراءة/الكتابة في ملف GitHub |
| `.env.example` | قائمة بالمتغيرات السرية المطلوبة (بدون قيم حقيقية) |

## الخطوة 1: إنشاء مستودع البيانات الخاص

1. على GitHub، أنشئ مستودعًا جديدًا، مثلًا باسم `it12-students-data`، واجعله **Private**.
2. أضف ملفًا واحدًا باسم `students.json` ومحتواه فقط:
   ```json
   []
   ```

## الخطوة 2: إنشاء رمز دخول محدود الصلاحية (Fine-grained Token)

1. اذهب إلى [github.com/settings/personal-access-tokens](https://github.com/settings/personal-access-tokens) → **Generate new token (Fine-grained)**.
2. **Repository access**: اختر **Only select repositories** ثم حدد مستودع `it12-students-data` فقط (وليس كل حسابك).
3. **Permissions → Repository permissions → Contents**: اختر **Read and write**. اترك كل الصلاحيات الأخرى بلا تغيير.
4. أنشئ التوكن وانسخه فورًا (لن يظهر لك مرة أخرى).

> **لماذا "Fine-grained" ومحصور بمستودع واحد؟** حتى لو تسرّب هذا الرمز يومًا ما، أقصى ضرر ممكن هو التعديل على مستودع البيانات هذا وحده، وليس كامل حسابك على GitHub.

## الخطوة 3: رفع ملفات الموقع إلى مستودع منفصل

1. أنشئ مستودعًا آخر، مثلًا `it12-registration-site`، وارفع إليه كل ملفات هذا المشروع (عدا `.env.example` إن أردت، فهو للتوثيق فقط ولا يحوي أسرارًا).

## الخطوة 4: ربط المشروع بـ Vercel

1. سجّل الدخول إلى [vercel.com](https://vercel.com) بحساب GitHub.
2. **Add New → Project**، ثم اختر مستودع `it12-registration-site`.
3. اترك إعدادات البناء كما هي (Vercel يكتشف تلقائيًا أنه مشروع Node بسيط) واضغط **Deploy** مبدئيًا.
4. بعد انتهاء أول نشر، اذهب إلى **Project → Settings → Environment Variables** وأضف كل متغير من `.env.example` بقيمته الحقيقية:

   | المتغير | القيمة |
   |---|---|
   | `GITHUB_TOKEN` | الرمز الذي أنشأته في الخطوة 2 |
   | `GITHUB_OWNER` | اسم المستخدم/المنظمة المالكة لمستودع البيانات |
   | `GITHUB_DATA_REPO` | `it12-students-data` |
   | `GITHUB_BRANCH` | `main` |
   | `GITHUB_FILE_PATH` | `students.json` |
   | `ADMIN_PASSWORD` | كلمة مرور من اختيارك لدخول لوحة المعلم |

5. اذهب إلى تبويب **Deployments** واضغط **Redeploy** على آخر نشر (المتغيرات الجديدة تحتاج إعادة نشر لتُطبَّق).
6. سيعطيك Vercel رابطًا بالشكل: `https://it12-registration-site.vercel.app`

- **رابط الطلاب:** `https://it12-registration-site.vercel.app/`
- **رابط المعلم (لا تشاركه):** `https://it12-registration-site.vercel.app/admin.html`

## الخطوة 5: التجربة

1. افتح رابط الطلاب وسجّل بيانات تجريبية.
2. افتح مستودع `it12-students-data` على GitHub وتأكد أن `students.json` تحدّث فعليًا وظهر سجل جديد + Commit جديد.
3. افتح رابط `admin.html`، أدخل `ADMIN_PASSWORD` الذي وضعته، وتأكد من ظهور السجل، ثم جرّب زري **تصدير JSON** و**تصدير CSV**.

## ملاحظات أمان مهمة

- رمز GitHub (`GITHUB_TOKEN`) لا يظهر أبدًا في كود المتصفح — هو موجود فقط كمتغير بيئة على خوادم Vercel، ولا يراه الطلاب مهما فعلوا (View Source أو أدوات المطوّر).
- كلمة مرور المعلم أيضًا تُتحقق منها في الخادم فقط (`ADMIN_PASSWORD`)، وليست مكتوبة في أي ملف يصل إلى المتصفح.
- كلمات مرور الطلاب تُحفظ في `students.json` بعد تشفيرها (SHA-256)، وليست نصًا واضحًا — لكن هذا لا يعني أنها مناسبة لإعادة الاستخدام في حسابات أخرى، نبّه الطلاب لهذا.
- حتى مع هذه الاحتياطات، بيانات الطلاب (الاسم ورقم الهاتف) معلومات شخصية — احتفظ برابط `admin.html` لنفسك، وتجنّب نشره في أي مكان عام.

## حذف أو تعديل سجل طالب

افتح مستودع `it12-students-data` على GitHub → افتح `students.json` → اضغط تعديل (✏️) → عدّل أو احذف السجل المطلوب يدويًا → احفظ (Commit). التغيير سيظهر فورًا في لوحة المعلم.

## أسئلة شائعة

**هل هناك تكلفة؟**
لا، الخطة المجانية من Vercel وGitHub تكفي بسهولة لعدد طلاب مدرسة كاملة.

**ماذا لو سجّل طالبان في نفس اللحظة تقريبًا؟**
دالة `register` تعيد المحاولة تلقائيًا عدة مرات في حال حدوث تعارض كتابة متزامن، فلا تُفقد أي بيانات.

**هل يمكن استخدام دومين مخصص بدل رابط vercel.app؟**
نعم، من `Project → Settings → Domains` يمكنك ربط أي دومين تملكه.
